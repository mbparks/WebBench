WebBench 0.15.1 · Green Shoe Garage
Universal Mac app and source repository · macOS 15 or later

OPEN WEBBENCH
Extract the ZIP in Finder, open the WebBench folder and double-click
WebBench.app. It is the universal v0.15.1 developer preview for Apple silicon
and Intel. You can also copy it to Applications. If macOS declines the
ad-hoc signed preview, use the local build instructions below.
It starts with an empty page and the Insert palette. Command-N makes another
free canvas. Expand or collapse the trays in Insert, or search all 80 parts.
File > New Studio Portfolio opens a designed page with an embedded
field-recorder photograph that you can replace.

PLACE AN ELEMENT
Drag a part from Insert and release it where you want it. You can also
click a tile and then click the spot on the page. New and reopened free
canvases start in Page canvas mode, so parts can overlap. Choose Container
above the palette to put the next part inside an existing layout.

ADD CODE OR AN IFRAME
Open Insert > Code & embeds. Drag Code snippet to display literal code or
Custom HTML to add a working widget. Drag Iframe embed and enter a URL
and title, choose another page from the project, or paste embed code.
Click Insert. Double-click the item to edit it again.
In Preview, try a local frame or inline document. For online embeds,
choose File > Preview Website in Browser. The snapshot includes current
edits. Some providers require the page to be hosted on HTTPS.
Open Fixtures/Snippets-and-embeds.html for an offline working example.

PLACE A SHAPE
Open Insert > Layout and scroll to Shapes, or type Shapes in the element
search. Drag Star onto the free canvas. Click its center, pull a corner
handle, and change Element background in the Inspector. Save the page
and open it in your browser. Try Arrow in the search to see four directions.

TRY THE DEVICE WORKBENCH
Choose File > Try Device Workbench. Select Apply & preview, then Connect
serial, Send line and Read line. The received text should say PING. Try
Start camera and Take snapshot, or move to the microphone and start it.
Preview supplies a color-bar frame, a sample meter and loopback data.
Select Stop preview, click a button and reopen Interactions to edit it.

Choose File > Export Website Folder to test physical devices. Serve that
folder over HTTPS or localhost and open it in desktop Chrome. For a local
test with Python 3 installed, open Terminal in the exported folder and run
  python3 -m http.server 8000 --bind 127.0.0.1
Open http://127.0.0.1:8000/ in Chrome. Connect or Start opens the browser
permission flow. Match serial baud or USB interface and endpoint settings
to your instrument. Press Control-C in Terminal when finished.

TRY THE POWER METER
Choose File > Try Power Meter Workflow. The open workflow checks whether
the form is valid. Its Then branch multiplies two live inputs and formats
the result to two decimal places. Its Otherwise branch displays a prompt.
Choose Apply & preview and press Measure power. Expect 3.00 W for 12 V
and 0.25 A. Clear Current and press Measure power again. Stop preview,
change the decimal places, apply and save to keep the edited workflow.

TRY A BUTTON INTERACTION
Choose File > Try Interaction Example. In the right-hand workflow, change
the first step’s text from “Signal acquired” to your own message. Choose
Apply & preview and press Test signal. Stop preview to keep editing.
For your own site, select a button, click Interactions and use Pick to choose
the target on the canvas. Save after applying. Page workflows lists the
handlers you can reopen and edit. Upload needs a receiving server. Test
upload rehearses the file selection locally in the offline preview.

BUILD A SECTION AND TRY LAYERS
1. Drag Section from Insert onto the blank page. Choose Container above the
   palette to nest the next part. Drag Button onto the middle
   of the section. Check the destination label, then release. Double-click
   the button text to rename it. Press Escape to finish.
2. In Layers, select the section. Choose Add inside > Layout > Container.
   Select the new container and choose Add inside > Text & lists > Disclosure.
   This also works with empty or covered containers in existing sites.
3. Drag the button row onto the highlighted middle of Container to nest it.
   Drag to the top or bottom edge of Disclosure to change their order. Try
   Option-Command-Up/Down to reorder, Right to nest, or Left to move out.
   Choose Review changes in the bottom bar, undo with Command-Z, then redo with Shift-Command-Z.
4. Switch to Insert. Search for grid, nav, audio, table or range. To overlap
   objects at page level on a free page, choose Page canvas above the palette.
   Switch back to Container to target the nearest compatible layout again.
5. Save, reopen, and inspect the tree. Choose Phone, Tablet or Desktop to
   check the layout. Choose Export > Website folder, then open index.html
   independently in Safari. Current HTML file exports a single-file page.

TRY THE PHOTO TOOLS
Drop a large JPEG, HEIC, PNG or TIFF from Finder onto the canvas. WebBench
offers a resized copy. For a quick edit, try 1280 px, Warm and a Mat border.
Compare Original and Edited, then choose Resize and insert. Cancel leaves
the page untouched. The original photo stays on disk.

For a photo already on the page, select it and choose Edit photo in
Inspector > Style. In Crop, draw a rectangle on the original.
Choose Edited to check the result and Apply to photo. Command-Z restores
the previous image. You can try this on the Studio Portfolio photograph.

SAVE, UNDO AND OPEN EXISTING WORK
Command-Z and Shift-Command-Z undo and redo source edits across views.
Command-S saves the working project. A new free canvas has a real draft file
under ~/Library/Application Support/Green Shoe Garage/WebBench/Drafts. File > Show Project in Finder
reveals it. Use Command-O to open your own page or site folder. Existing
flow, flex and grid layouts use their original source and placement rules.

BUILD FROM SOURCE
Select the installed Xcode in Xcode > Settings > Locations > Command Line
Tools if xcodebuild cannot find the macOS SDK. In Terminal, the equivalent command is

    bash Build-WebBench.command

The script builds the shared scheme, signs that local app and reveals it in
Finder. Logs are under build/local.*/build.log.

CHECK ON A MAC
File > Run Sample Checks… exercises fourteen groups using disposable files.
Group 14 edits the power meter, checks Undo/Redo and tests both branches
in WebKit after saving and reopening. Group 13 inserts into nested flex, moves a layer into an empty container,
undoes and redoes, adds a disclosure, saves and reopens. The checks window
can also open the Field Instrument in Safari and record your observation.
Physical Mac input, native launch and independent Safari verification are
pending for this build. See docs/ACCEPTANCE.md and docs/VALIDATION.md.
